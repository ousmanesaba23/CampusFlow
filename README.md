# CampusFlow

Application Flutter de gestion d'échanges entre étudiants, réalisée à partir du brief de l'atelier « Trois écrans de CampusFlow ».

## Fonctionnalités

- Liste d'échanges avec recherche, filtres, cartes et bouton d'ajout.
- Fiche détaillée d'un échange et action pour le marquer comme terminé.
- Formulaire avec validation des champs et confirmation par SnackBar.
- Mise en page adaptative : liste et détail côte à côte à partir de 840 px.
- Navigation Material 3 et données de démonstration en mémoire.

## Lancer le projet

Prérequis : Flutter stable installé.

```sh
flutter pub get
flutter run
```

## Dépôt Git

Ce dossier est un dépôt Git local. Le projet n'est relié à aucun hébergeur distant.

Pour le publier sur un hébergeur Git, créez un dépôt vide puis exécutez :

```sh
git remote add origin <URL_DU_DEPOT>
git push -u origin main
```
